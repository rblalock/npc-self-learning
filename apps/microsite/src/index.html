What this does—and doesn’t—establish

Preferences really change, and continued learning can improve measured combat outcomes. It can also make them worse. This is a small contextual bandit choosing authored tactics. It does not invent maneuvers, read hidden player inputs, or raise enemy stats.

Human enjoyment remains unmeasured. The longer guided playtest is ready; automated QA is labeled and excluded from human findings. The later qualified-task and noisy-history studies extend this record. Scripted controllers and limited platform checks still do not establish broad game or platform support.

04 / Make it yours

A small learning layer.
Your game around it.

Rust at the core. WebAssembly in the browser. MIT-licensed source, versioned downloads, and an independent example to start from.

Start with the browser kit

Extract, serve the folder over HTTP, and run the guard example. It includes the compiled library and typed client.

python3 -m http.server 8080

Or run the Rust host from the source bundle:

cargo run --locked --release \
  -p tactical-air-core --example guard_host
